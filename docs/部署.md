# 部署到 VPS（给女朋友用，Mac 能睡着）

目标：把 booktalk 跑在一台 7×24 开机的服务器上，你和女朋友各自用浏览器打开同一个网址就能用（共用你的 DeepSeek key）。你本地的 Mac 随便睡。

## 0. 你需要什么
- 一台 **VPS**：**2 核 4GB 内存、20GB 磁盘**（bge-m3 嵌入 + 重排 + Whisper 要 ~4GB 内存）。机房挑**香港/新加坡**（国内能直连、不用备案）。
  - 国内省心：腾讯云/阿里云「轻量应用服务器」香港区（约 ¥50/月，4GB）。
  - 国外：Vultr / DigitalOcean 新加坡/东京（约 $6–12/月）。
- 一个**域名**（如 `booktalk.你的域名.com`），把 A 记录指向 VPS 的 IP。Caddy 会自动签 HTTPS。

## 1. 装 Docker（Ubuntu/Debian 一键）
```bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER   # 然后退出重新登录
```

## 2. 拉代码
```bash
sudo mkdir -p /opt/booktalk && sudo chown $USER /opt/booktalk
git clone https://github.com/AvenueG/booktalk.git /opt/booktalk
cd /opt/booktalk
```

## 3. 配域名
```bash
cp .env.example .env
# 编辑 .env，填上你的域名：
#   BOOKTALK_DOMAIN=booktalk.你的域名.com
```

## 4. 启动（首次会下载模型，要几分钟）
```bash
docker compose up -d --build
docker compose logs -f app   # 看模型下载/启动进度
```
看到 `Uvicorn running on http://0.0.0.0:8000` 就是好了。

## 5. 填 API Key
浏览器打开 `https://你的域名` → 右上角「设置」→ 粘贴你的 DeepSeek key → 保存。
（key 存在 `data/config.json`，随 `booktalk-data` 卷持久化，重启不丢。）

## 5.5 设邀请码（推荐）
同一个「设置」面板里，给「邀请码」设一个口令保存。之后别人打开网址会先看到解锁页：

- 输入**邀请码** → 用你的 API（你出钱），这是给你女朋友的。
- 没有邀请码就填**自己的 DeepSeek Key** → 用他们自己的 API（他们自己出钱）。

把邀请码发给你女朋友就行。想改/关掉，回设置面板改邀请码（留空保存 = 关闭门禁）。

## 6. 之后每次更新：git push 自动部署
在 GitHub 仓库 **Settings → Secrets and variables → Actions**，加三个 secret：
- `VPS_HOST`：服务器 IP
- `VPS_USER`：登录用户名（如 root）
- `VPS_SSH_KEY`：SSH 私钥（在服务器上 `ssh-keygen` 生成，公钥放进 `~/.ssh/authorized_keys`）

之后你本地改完代码 `git push`，GitHub 会自动 SSH 上去 `git pull` + 重建重启。女朋友那边刷新页面就是最新版。

## 7. 常用命令
```bash
docker compose logs -f app      # 看日志
docker compose restart          # 重启
docker compose down             # 停止（不删数据）
docker compose up -d --build    # 更新后重建
```

## 8. 故障排查
- **内存不够（OOM）**：机器至少 4GB；`docker compose logs app` 看到 `Killed` 就是内存爆了。可设 `MODEL_DEVICE=cpu`，或换更小嵌入模型。
- **首次很慢**：模型（bge-m3 ~2GB + whisper）第一次要下载，`docker compose logs -f app` 能看到进度；之后走 `hf-cache` 卷不再下载。
- **域名打不开/没 HTTPS**：确认 A 记录指向 VPS IP，且 80/443 端口在安全组/防火墙放行。
- **模型下载连不上**：`.env` 里设 `HF_ENDPOINT=https://hf-mirror.com`（国内网络）或 `https://huggingface.co`（国外 VPS）。

## 安全提醒
- 网址现在没有密码，任何拿到链接的人都能用。就你俩的话够用；想加个防白嫖的访问密码，回来我再给你加一层。
